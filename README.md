For this mini-project, following the suggestion from @letici4swwd on Instagram, who suggested that I create a drawing of Lain using the same aesthetics I used for Miku, I brought back the same typographic art technique using code (HTML5 Canvas, CSS, and JS)... Lain’s image is formed entirely through the continuous repetition of the word “LAIN”, constantly moving to the left. The result combines this fluid text animation with a neon green color palette.

Slowed version is script.js. Faster (ORIGINAl) version is script.js_old. Remove "_old" to get the faster file. Changed it for myself as it hurts my eyes.
